# rhoT（论文二）· 2026-11-05 · ρ_t 首测：分步到底需不需要

> **本 summary 于 2026-11-07 11:00 补写**（当时只落了 CSV 与图）。
> 数字全部从 `e0_rho.csv`（60 行）**重新复算**，与 §8.1 的日志记载逐项对上（3.37/3.25/2.75 完全一致）。

## 目的（这是论文二的第一个闸门）

全篇的核心主张是"w 与 s 不是两个独立旋钮"，其数学形式要求**每一步 t 的引导贡献系数 ρ_t 不同**。
如果 ρ_t 在整个去噪过程中近似常数，那用一个全局标量就够了，"分步共线"这个框架就没有存在必要。
所以这一测不是为了得到好看的曲线，而是**决定要不要继续做下去**。

## 设定

| 项 | 值 |
|---|---|
| 基座 | SD1.5 fp16，DDIM **20 步** |
| 采样方式 | 在**同一条 base 轨迹**的每个 x_t 上做四次前向（base/LoRA × 条件/空提示）——轨迹固定，ρ_t 的差异只能来自系数本身，不混入轨迹漂移 |
| LoRA | 受控合成扰动：**64 个 cross-attn 投影，rank 4，‖ΔW‖=0.05‖W‖** |
| 扫描 | t ∈ 20 个采样点（`t_frac` .001→.951），3 个 prompt（person / style / object） |
| 记录量 | `rho`（引导方向与 LoRA 方向的内积投影）、`align`（余弦）、`spur`（虚假相关比）、`g_eff_unit`（单位 w 的等效增量） |

## 结果一：ρ_t 跨步变化 **2.75–3.37 倍**，闸门通过

| prompt | ρ 的范围 | 跨步倍数 |
|---|---|---|
| person | .1071 – .3612 | **3.37×** |
| style | .0826 – .2682 | **3.25×** |
| object | .0892 – .2458 | **2.75×** |

三 prompt 均值序列（按 t_frac 从小到大）：

```
t≈0    0.230  ← 起点较高
t=.30  0.184  ← 中前段下探
t=.55  0.275  ← 全段峰值
t=.95  0.093  ← 末端最低
```

跨 prompt 汇总的 max/min = **2.96×**。

**判定**：远大于 1（合同阈值是 >3 倍→强成立、<2 倍→退回全局版；实测 2.75–3.37，**落在成立一侧但贴边**）。
所以"用单一全局标量会把某一段 t 上的结论算错"这件事成立——**分步框架保留**。

## 结果二：三个辅助量各有用途，但都不能单独当证据

| 量 | 行为 | 用途 |
|---|---|---|
| `align` | **−.37 到 +.37**，围绕 0 大幅摆动，中段多为负 | 说明 LoRA 方向与引导方向**经常不共线**——这正是"两个旋钮会互相干扰"的微观来源，但它本身不能定量 |
| `spur` | 从 t 大端 **≈.87 单调升到 t 小端 4.3–5.9** | 早期步（t 大）的估计更"干净"，末期步的投影被基座自身的主导方向污染 → **末段数据要谨慎** |
| `g_eff_unit` | 量级 **.001–.24**，中段（t=.2–.5）出现负值 | 单位 w 的等效增量在部分区段**反向**，这是 @E3a 后来"w=1 时 +9.6% 而 w=2 时 +81.6%"非线性的首条线索 |

## 结果三（必须与后文连读）：本实验的**形状结论已被 E2b 推翻**

本实验当时看到"ρ_t 呈驼峰（峰在 t/1000≈.60 与 .36）"，但 **E2b（§8.2）做幅度扫描后发现峰位随 w 移动**：
w=.02 时三 prompt 峰都在 t=.001，w≥.05 才移到 .55–.60。→ **「ρ_t 是驼峰」这个说法作废，已列入红线。**

本实验**仍然有效的部分**只有两条：

1. **跨步变化 ≥2.75 倍**（分步必要性的方向性结论；E2b 复测得 2.2–5.05，同一量级）。
2. **align 在 0 附近大幅摆动**（这是"两条路径不完全共线"的直接证据）。

**不可引用的部分**：峰的位置、峰的数量、ρ_t 的绝对幅值。

## 判定

| 问题 | 答案 |
|---|---|
| 分步 ρ_t 有必要吗 | **有**（2.75–3.37×，三 prompt 一致）。闸门 B 通过 |
| 能报 ρ_t 的曲线形状吗 | **不能**（峰位随 w 移动，E2b 已推翻） |
| 能报 ρ_t 的绝对幅值吗 | **不能**（依赖 LoRA 幅度 rel=.05 这个人为设定） |
| 这一测留下了什么 | ① 分步必要性的首条证据；② `align` 摆动的定性事实；③ `g_eff_unit` 中段反号 → 非线性膨胀的线索，直接引出 E3a |
