# E2c — 用真 SD1.5 LoRA 复现 E2b 的幅度扫描

**日期**：2026-11-06
**脚本**：`e2c_real_lora.py`（测量）、`e2c_plot.py`（出图）
**数据**：`e2c_real_lora.csv`（240 行 = 3 prompt × 4 档 w × 20 步）
**图**：`fig_e2c_real_lora.png`（上排 E2c 单独，下排与 E2b 逐 prompt 对照）
**LoRA**：`models/lora/lora_detail_sd15.safetensors` —— MusePublic/1_lora_SD_1_5 的 `14.safetensors`，"Add More Details" rank-8 LoRA，kohya 格式，792 张量，覆盖 text encoder + UNet 的 attention/FFN 全层

## 1 为什么必须做这个

E2b 用的是**合成 rank-4 扰动**：64 个 cross-attn 投影，同一方向，幅度归一化。真 LoRA 不一样：rank 8、192 层、层间异质、还改了 text encoder。

如果 α_t 的形状只是合成扰动的产物，论文二的 I1 就撑不住。

**一个设计上的好运气**：真 LoRA 在 w=0 时不起作用，所以 E2c 的 base 轨迹与 E2b **完全相同**（同 seed、同 prompt、同 20 步 DDIM）。两组唯一差别就是扰动族，是干净的 A/B。

## 2 关键数字：真 LoRA 的幅度比合成扰动小一个量级

| | 幅度指标 | 数值 |
|---|---|---|
| 真 LoRA（w=1） | \|ΔW\|/\|W\| over 192 层 | **median 0.0121**，p10 0.0081，p90 0.0380 |
| E2b 合成扰动 | rel | 0.02 / 0.05 / 0.10 / 0.20 |

也就是说 E2b 的最小档（0.02）已经约等于真 LoRA 的 **w≈1.65**，而 0.1–0.2 相当于 w≈8–16，**远超实际使用范围**。E2b 因此把曲线推到了更深处。

自检：\|ε(w=1)−ε(w=0)\|/\|ε(w=0)\| = 0.0123，与 ΔW/W 的 1.2% 吻合，说明 adapter 确实生效且度量一致。

## 3 结果一：摆动幅度 ≥2.0×，且与 w 几乎无关

| prompt | w=0.25 | w=0.5 | w=1.0 | w=1.5 |
|---|---|---|---|---|
| person | 2.43 | 3.29 | **3.47** | 3.10 |
| style | 2.03 | 2.15 | 2.16 | 2.07 |
| object | **4.11** | 3.80 | 3.89 | 3.88 |

与 E2b（2.20–5.05）一致：**核心主张「单一标量 ρ 不够」在真 LoRA 上成立，最保守也有 2.0×。**

注意一个差别：E2b 的摆动随幅度**单调增**（2.5→5.0），E2c 的摆动**基本平坦**（w 从 0.25 到 1.5 几乎不变）。原因还是幅度——真 LoRA 落在线性区，放大 w 不改变形状，只放大整体。

## 4 结果二：峰值位置随 w 移动，与 E2b 同向

| prompt | w=0.25 | w=0.5 | w=1.0 | w=1.5 |
|---|---|---|---|---|
| person | **t=0.001** | 0.701 | 0.701 | 0.701 |
| style | 0.001 | 0.001 | 0.001 | 0.001 |
| object | 0.001 | 0.001 | 0.001 | 0.001 |

person 在最小幅度时峰在最低噪端，w≥0.5 后移到中段——**和 E2b 的规律一模一样**。style/object 始终在低噪端（E2b 里 object 在 w≥0.1 后也移到 0.551，这里没移，因为真 LoRA 的等效幅度更小）。

**再次确认：「ρ_t 是驼峰」不能写；「峰位依赖幅度」才是真的。**

## 5 结果三（核心）：α_t 同形状，但真 LoRA 更温和

| t/1000 | person | style | object | R²(min) |
|---|---|---|---|---|
| 0.951 | 0.81 | 0.92 | 0.76 | 0.972 |
| 0.751 | 1.03 | 0.82 | 1.00 | 0.993 |
| **0.601** | 0.95 | 0.88 | 0.94 | 0.999 |
| **0.551** | 0.94 | 0.90 | 0.95 | 0.998 |
| 0.351 | 0.93 | 0.90 | 0.97 | 0.998 |
| 0.151 | 0.91 | 0.95 | 0.92 | 0.994 |
| **0.001** | **0.75** | **0.86** | **0.83** | 0.977 |

**真 LoRA：α_t ∈ [0.746, 1.031]，中段≈1、两端 0.75–0.86。
合成扰动（E2b）：α_t ∈ [0.563, 1.028]，中段≈1、两端 0.56–0.75。**

两者**形状完全一致（L 形：中段贴着 1，两端下垂），真 LoRA 的下垂更浅**。下排三个子图逐 prompt 对照，三条曲线都平行。

**解释**：α 的下垂来自饱和。真 LoRA 幅度只有 1.2%（约 E2b 最小档的一半），离饱和区更远，所以下垂更浅。**幅度越大、下垂越深**，这与 E2b 内部"w 越大摆动越大"是同一件事。

## 6 对论文的影响

**I1 保住了，而且现在有两个独立证据源：**

> 在真实 SD1.5 LoRA（rank-8，192 层，含 text encoder）上，ρ_t 沿去噪轨迹摆动 **2.0–4.1×**，局部弹性 α_t ∈ **[0.75, 1.03]**，中段近似线性、两端下垂；低 w 时峰落在最低噪端，w≥0.5 后移到中段。合成 rank-4 扰动（幅度 2–20%）给出**同形状但更陡**的版本（α 0.56–1.03），说明下垂深度由幅度决定。

可写的最强表述：**「式(1) 把 ρ 当常数，在两端会高估 w 的作用；在实用幅度（ΔW/W ≈ 1%）下偏差约 20–25%（1−0.75）」**。这个 20–25% 是实测的，不是估计。

**但要克制**：不能写"ρ 是幂律"，也不能说"线性模型完全失效"——真 LoRA 上 α 只降到 0.75，偏差四分之一，是"需要修正"而不是"必须推翻"。

## 7 局限

1. **只有一个 LoRA**（"Add More Details" 细节增强型），且它不是概念/身份型。论文二讲身份一致性，最好再补一个**人物/风格** LoRA。
2. 只有 3 个 prompt、20 步 DDIM、512×512、单 seed。
3. 幅度范围由这一个 LoRA 的固有 ΔW 决定（1.2%），w 只能到 1.5，再大就出图崩坏，没有覆盖 E2b 的高幅度区。
4. α 的机制（softmax 饱和）仍是解释，未独立验证。

**下一步 E2c-2**：再找一个**概念/人物型** SD1.5 LoRA（rank 4 或 8），确认 α_t 的 L 形不随 LoRA 类型变。
