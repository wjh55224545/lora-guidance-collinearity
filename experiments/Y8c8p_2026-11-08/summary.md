## 目的

§8.28 撤回了"负向提示词削弱共线"，§8.29 又发现具体名词降得和画质词一样多——这两条**互相矛盾**：
若"非空即降"成立，画质词也该在 obj04–07 上降（它没有）；若是"特定字符串"，具体名词凭什么和画质词打平。
唯一能分开的做法：把 content 档补齐到 8 个 prompt，看它在**四个画质词失效的新 prompt** 上是否也失效。
§8.28 的那四个新 prompt 同时是"效应是否存在"的分水岭，两个候选（算子效应 / prompt 条件性）此前完全混淆。

## 设定

同 tag 续跑 `--prompts 8`（`y_gen` 只补 obj04–07，4 prompt × 45 = 180 图 / 10 min）。
网格 5w × 9s、seed 11、度量 `pix_l2`、grid + local 同报，与 §8.29 完全一致，数字可直接拼接。

## 判定

1. ✅ **「非空负向分支降低 κ」复现**，且在新 prompt 上更强（−.181，p=.006，4/4）。
   → §8.28 的撤回**必须收窄**为"画质词串那条不成立"，**不能**写成"负向提示词无效"。
2. ✅ **画质词不是原因，具体名词更强**（新 prompt 上差 −.152，p=.006）。
3. 📌 **机制的正确写法**：不是"负向语义"，也不是"单纯非空"，而是 **"无条件分支装的具体内容"**。
   强度顺序（具体名词 > 画质词 > 另一组画质词）**不由语义类别预测**，必须如实写。
4. ⚠️ **仍然不是一个"手段"**：obj02 反向（+.054）、obj06 的 κ 变负（−.053）；
   κ=.084 时 s\*(w) 仍降 29.7% → 共线没被消掉。正文只能写"空字符串是共线最强的一档"。
5. 📌 **对 §8.29 方差分解的修正**："算子不是可加因子"**要降级**——那 26–29% 的 R² 是在一对**弱算子**
   （画质词两版）上算出来的，不能外推成"算子不重要"。
6. ✅ 论文主线不变：κ 在所有算子下都 ≪ 1；额外得到一个**可写的算子效应**：
   `空 → 具体名词` 使 κ 从 .228 降到 .084（8 prompt，7/8 同向，p=.004）。

## 正文改动

1. **恢复**一条算子结论，按内容写：**把空负向换成四个具体名词 → κ .228→.084（grid，7/8，p=.004；
   local .178→.093，6/8，p=.022）**；s\*(w) 降幅 33.7%→29.7%，`edge_share=0`。
2. **删掉**"画质词削弱共线"；画质词只作为"强度不可预测"的证据出现在限制段。
3. 限制段两句：① obj02 反向、obj06 变负 → 不普适；② 强度顺序不由语义预测，只能逐串实测。
