# Y7-neg-8p · 负向提示词那一条在 4 个新 prompt 上效应为零 —— 撤回

- **日期**：2026-11-08 06:12 → 06:44（两段各 360 图，共 720 图 / 30.6 min）
- **论文**：论文二《身份与引导不是两个独立旋钮：LoRA 权重尺度与引导强度的分步共线》
- **上游**：`../Y7dose_2026-11-08/`（§8.27 剂量证伪）、§8.24（原始 4 prompt 的 neg 观察）
- **一句话**：把"负向提示词使 κ 下降"从 4 个 prompt 扩到 8 个，**在四个从未用过的新 prompt 上效应为零**
  （grid −.030 p=.46、local −.000 p=.99，符号 1/4 与 2/4）；8 个合起来 −.081（p=.077）方向一致但不显著。
  → 与剂量证伪一起构成两条独立证据：**该结论从正文删除**。但"所有算子下 κ ≪ 1"反而更稳（neg 均值 .144）。

## 目的

§8.24 的"负向提示词把 κ 砍半"和 §8.27 的剂量证伪，都建立在 **4 个 prompt 的配对检验**上，
而 4 词档 p=.13 这个数字本身没有信息量：它离显著只差一步，两种解释（真有效但欠功效 / 本来就没有）同样成立。
把两个端点（空 vs 4 词 neg）在 **obj00–obj07 八个 prompt** 上重跑（全部 object 类，`pclass` 与 `ρ` 同口径），
后 4 个作为**独立复现集**——它们在此前任何算子对比里都没出现过。

## 设定

`y_gen --mode single --lora full=full`，9 点 s（3, 4, 5, 6, 7.5, 9, 10.5, 12, 14）、5 档 w（0.2–2.0）、seed 11，
每段 360 图（8 prompt × 5w × 9s）。度量 `pix_l2`（**不用 `pix_l2_base`**：本 run 的参考点在 w=W0=1.0，
该度量在 w=1.0 处为零，喂给 argmin 会挖掉 w 轴中段并把 κ 从 .185 抬到 .306）。估计器 grid 与 local 同报。

## 结果

逐 prompt κ（grid），Δ = neg − empty：

| prompt | empty | neg | Δ |
|---|---|---|---|
| obj00 | .230 | −.014 | **−.243** |
| obj01 | .187 | .065 | −.122 |
| obj02 | .065 | .111 | +.046 |

| obj04 | .306 | .306 | .000 |
| obj05 | .255 | .255 | .000 |

| 组 | n | grid 均值 Δ | p | local 均值 Δ | p |
|---|---|---|---|---|---|

| **obj04–07（新 4 个）** | 4 | **−.030** | **.458** | **−.000** | **.992** |

负号占比：grid 4/8（原 3/4、新 **1/4**）；local 5/8（原 3/4、新 2/4）。

## 判定

1. ❌ **不复现**：四个新 prompt 上 grid −.030、local −.000，符号 1/4 与 2/4
   → **"负向提示词削弱共线"从正文撤回**（与 §8.27 剂量证伪是两条独立证据）。
2. ⚠️ 8 个合起来 −.081（p=.077）方向一致但不显著，效应量只有 §8.24 报的一半。
   只能写"在这批 prompt 上观察到更低的 κ"，不能写成性质。
3. 📌 **效应集中在 obj00 与 obj03**（−.243 / −.209），obj02 与 obj07 反向 → prompt 条件性，不是算子性质。
4. ✅ **主结论不受影响**：即便在最不利的 neg 档，κ 仍只有 .144（8 prompt 均值），离 1 有 7 倍。
5. ⚠️ **obj04 / obj05 的 κ 在两算子下逐位相同（.306 / .255）**，形似串台，已核**不是**：
   两 run 的图像路径不同、`pix_l2` 逐格只有 1/72 相同。原因是 grid 估计器的 s\* 只在 9 个格点上取值，
   κ 被量化为少数几档，8 个 prompt 撞两次属正常。**这条要进方法节**，否则审稿人会当 bug。
6. 📌 **方法教训**：真实效应约 −.08 时 n=4 的配对 t 几乎不可能显著 → 以后算子对比一律 ≥8 prompt。

另记一个代码坑：`T.neg - T.empty` 里 `T.empty` 是 **DataFrame 的布尔属性**，不是列，
结果 diff 恒等于 neg、且"负号占比"全错（首版报 1/8、−0.147）。必须写 `T["neg"] - T["empty"]`。

## 正文改动

1. **删除**"负向提示词使 κ 下降"；§8.24 标题补"（仅在 4 个 prompt 上）"。
2. 算子里程碑只剩一档硬结论：naive / rescale 同量级（.159 → .165）；neg 只作脚注。
3. 方法节补：grid 估计器在 9 点 s 上会**量化**（不同 prompt 可撞同值），算子间比较一律用 8 prompt 均值。
