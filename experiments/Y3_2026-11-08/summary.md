# Y3 · 两个 LoRA 同时加载：漂移是否可加，谁丢掉了杠杆

- **日期**：2026-11-08 03:28–03:42（生成 13.8 min）＋分析/作图
- **论文**：论文二《身份与引导不是两个独立旋钮》
- **目的**：社区规则说"叠 LoRA 就要把引导调低，总强度超过 ~1.5–2 它们会打架"。
  这条规则没有任何人给出数字。Y3 把它变成一个**可分离性检验**：
  若 `d(wA,wB,s) = f(wA,s) + g(wB,s) + c`，则两个适配器作用在独立方向上，
  **两个旋钮仍然成立**，剩下的只有 (w,s) 共线；若 wB 上升时 wA 轴的斜率**收缩**，
  则 wB 吃掉了 wA 的一部分杠杆，**有效旋钮数 < 2**——这是 I1 在"组合"一侧的同型现象。

## 设定

| 项 | 值 |
|---|---|
| 适配器 | A ＋ B（Y1 独立训练的两个 checkpoint，`lora_A.safetensors` / `lora_B.safetensors`） |
| 权重网格 | `wA × wB ∈ {0, 0.3, 0.6, 1.0, 1.5}²`（25 格） |
| 引导强度 | `s ∈ {5, 7.5, 10}` |
| prompts | 4 个，全部为 object 类（obj00–obj03） |
| seed | **仅 11**（单 seed） |
| 图像总数 | **300**（4 × 25 × 3），2.60 s/img 中位，13.8 min |
| 因变量 | `pix_l2_base`（同一 run 内生成的**无 LoRA** 参考图，整张 5×5 网格在同一坐标系） |

三个统计量（全部**在每个 s 切片内**算，绝不跨 s 合并）：

1. **可加拟合** `D[i,j] = μ + a_i + b_j` → R² 与残差标准差（残差即交互项）
2. **轴收缩** wA 轴斜率（对 wA 回归）在 `wB=0` 与 `wB=1.5` 处的比；另加一个内部区间版本
   （`wA∈[0,1.0]`，`wB=0` vs `wB=1.0`），因为 1.5 端点可能落在平尾/非单调尾上
3. **联合 / 之和**：`D(1,1)` 对 `D(1,0)+D(0,1)`；次可加是"打架"的定量形式，超可加则直接否证社区建议

## 结果

### 可加拟合

| s | n | R² (additive) | 残差 sd | wA 收缩 (0→1.5) | wA 收缩 (0→1.0) | wB 收缩 | joint/sum |
|---|---|---|---|---|---|---|---|
| 5   | 4 | 0.973 | 1.10 | 0.82 | 0.79 | 0.74 | 0.68 |
| 7.5 | 4 | 0.921 | 2.62 | 0.01 | 0.28 | 0.35 | 0.72 |
| 10  | 4 | 0.925 | 2.23 | 0.08 | 0.22 | 0.60 | 0.64 |

- **R² 中位 0.945**（IQR 0.860–0.966）→ 可加部分主导了整张 5×5 网格的方差
- **wA 轴收缩中位 0.09**（全区间）／**0.28**（内部区间）；**wB 轴收缩中位 0.51**
- **joint/sum 中位 0.68**，对 1 检验 **t = −11.77, p = 1.42e-07**（n=12，次可加）

### 逐 prompt（wA 收缩中位）

| prompt | wA 收缩 | R² | joint/sum | 备注 |
|---|---|---|---|---|
| obj00 | 0.130 | 0.947 | 0.786 | s=7.5 时 wB 满载后斜率为负 |
| obj01 | **−0.129** | **0.676** | **0.541** | s=7.5 与 s=10 **两格斜率为负** |
| obj02 | 0.035 | 0.904 | 0.680 | 无负斜率，但收缩最彻底 |
| obj03 | **0.691** | 0.975 | 0.672 | 唯一接近"两个旋钮"的 prompt |

**3/12 格在 wB 满载时 wA 斜率为负**（obj00@7.5、obj01@7.5、obj01@10）——不是"变平"，是**掉头**。
这正是必须加内部区间对照的原因：全区间比值在这些格上符号翻转。

### 判定（对照跑前写死的判据）

> 写死判据：`median(shrink) < 0.6` → "composition eats leverage，报数字不报规则"

- 全区间 **0.09 < 0.6**，内部区间 **0.28 < 0.6** → **判据命中，且两种口径都命中**
- joint/sum **0.68 < 1** 且高度显著 → **次可加**，与收缩方向一致
- 因此正文可写：**两个 LoRA 同时加载时，第二个适配器把第一个的杠杆削到 0.09–0.28 倍，
  合流强度只有各自单独之和的 0.68 倍。** 这是社区规则的定量形式。
- ⚠️ 但 **R² = 0.945 说明了另一面**：整体几乎可加，交互在**方差**意义上很小、
  在**导数**意义上很大。这两句必须同时写，只写一句都会误导。

## 关键警告与限制

1. **R² 高与收缩低并不矛盾**：R² 是整张网格的**方差加权**量，轴收缩是**端点导数**量。
   高 R² + 低收缩 = "大体可加，但第二个适配器恰恰在最需要杠杆的地方把第一个的杠杆拿走了"。
   这句话是 Y3 最该被引用的表述。
2. **A/B 不对称**：wA 收缩 0.09 对 wB 收缩 0.51——**后加载的 B 保住一半杠杆，先加载的 A 几乎被吃光**。
   → **已补 swap 对照判掉"顺序"这一解释**（见下 §补跑），不对称属于**适配器本身**；
   但**为什么** A 与 B 不同仍未知（只有一对适配器），所以只能说"B 的杠杆更抗组合"是**一个观察**。
3. **单 seed（11）、4 个 prompt 全为 object 类**：跨 seed 稳定性未测；类别效应未测
   （Y6 已证 prompt 类别对 κ 有影响，Y3 无法排除）。
4. **非单调尾**：1.5 端点本身可能过强，3/12 格斜率为负。内部区间对照是为此设的，
   结论对端点选择不敏感，但**收缩的精确数值依赖端点**，正文给区间而非单点。
5. **`pix_l2_base` 的参考图固定 S0=7.5**：每个 s 切片内存在常数偏移。三个统计量
   全是切片内的差或比，偏移抵消；但**跨 s 比较绝对值无意义**。
6. 只有**一对**适配器（A、B）。"叠 LoRA"在社区里包含不同 base、不同 rank、不同训练集的组合，
   Y3 的结论只覆盖"同源独立训练、同 rank"这一情形。

## 补跑 1 · Y3-swap：组合与顺序无关（300 图，15 min）

同样两适配器、同网格、同 seed，只把加载顺序换成 **B 先 A 后**（于是 `d_swap[i,j] = d_orig[j,i]`）。

| 量 | 值 |
|---|---|
| `corr(d_swap, d_orig^T)` | **1.0000**（12 格全为 1.0000） |
| `corr(d_swap, d_orig)` | .8532 |
| 收缩数 | `y3`：axis1(A) **.093** / axis2(B) **.511**；`y3_swap`：axis1(B) **.510** / axis2(A) **.093** |
| 逐字节核对 | `y3_swap/obj00_sd11_w0.3_w20_s5.png` 与 `y3/obj00_sd11_w0_w20.3_s5.png` **完全相同**（s=5/7.5/10 三张全 IDENTICAL） |

**判定**：
1. ✅ **组合是顺序无关的**（peft 的叠加就是 `Σ w_i·Δ_i`）→ **.09/.51 的不对称不可能是叠放顺序造成的**，
   属于两个适配器本身。原假说**被否**。
2. ⚠️ **相关恰好 1.0000 不是独立证据**：它等于 1 是因为**图逐字节相同**；真正被证实的是"顺序无关"，
   **不得**把 1.0000 当作"不对称来源被证实"的强度。
3. ⚠️ 仍不知 A 与 B 为何不同（一对适配器，且强度都是原 LoRA 的 2–7 倍）。
