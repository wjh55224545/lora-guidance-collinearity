# Y1 · 自己训练两个独立 LoRA

**一句话**：两个概念各训 1000 步、12–13 分钟，`pix_l2_base`（w=2）达 **21.3 / 25.5**，
远超 INERT 门槛 2.0 → **跨 LoRA 稳健性第一次有了干净的载体**（E2c-2 那五个变体全是同一 LoRA 的切片）。

- 运行：2026-11-07 23:42 → 2026-11-08 00:13（25.1 min，GPU）
- 产物权重：`models/lora/trained/lora_{A,B}.safetensors`（各 6.41 MB / 256 张量）

## 1 设定

| 项 | 取值 |
|---|---|
| 概念 A | 扁平矢量插画风（flat vector），teal–coral 双色 |
| 概念 B | 中国水墨（chinese ink wash），单色 |
| 概念数据集 | **用 base SD1.5 自生成 24 张**（12 subject × 2 seed）——不下载、不涉版权 |
| 适配层 | `LoraConfig(r=8, target_modules=[to_q,to_k,to_v,to_out.0])`，**1.59 M 可训参数 / 256 张量** |
| 训练 | 1000 步、batch 1、AdamW **lr 2e-4**、cosine + 50 步 warmup、`clip_grad_norm_(1.0)` |
| 显存 | fp32 UNet + 梯度检查点；VAE 潜变量与文本嵌入**预计算**，训练循环不碰 VAE |
| 有效性闸门 | w=0 作基准，`max pix_l2_base < 2.0` → **判 INERT**（= 没训上，**绝不能记成"无共线"**） |

## 2 结果

| 概念 | 墙钟 | 步速 | final loss | max `pix_l2_base`（w=2） | min（w=1） |
|---|---|---|---|---|---|
| A（flat vector） | 12.3 min | 640 ms/step | **0.1157** | **21.32** | 7.56 |
| B（ink wash） | 12.8 min | 610 ms/step | **0.1104** | **25.55** | 17.30 |

## 3 判定

1. ✅ **两个 LoRA 都不是 INERT**（21.3 / 25.5 ≫ 2.0），可作 Y2 / Y3 的载体。
   训练超参这套（rank 8、1000 步、lr 2e-4、24 张概念图）在 13 分钟内出可用 LoRA，以后加概念直接复用。
2. ✅ **B 比 A 更强也更均匀**：A 的 `obj00` 只有 7.56（概念在该 prompt 上弱），B 四个值全在 17–26。
   → **Y2_A 的 w 低端可能信号弱**，拟合时要盯 `s*` 是否贴住 s 网格边界（可识别性闸门会报）。
3. ⚠️ **红线（新）：不能说这两个 LoRA 代表"一般个性化 LoRA"**。编辑强度 `pix_l2_base` 21–25，
   换算到每像素平均差 ≈ **0.33（0–1 值域）**，而原 LoRA（`lora_detail_sd15`）只有 3–9。
   **这是强编辑条件**。若 Y2 在强编辑下仍测到 κ<1，"共线"更硬；但**外推到轻量风格 LoRA 要另测**。
4. ⚠️ 24 张概念图是 base 模型自生成的，**概念纯度不如人工数据集**（B 的"水墨"里混了 base 的写实倾向）。
   这只会**削弱**两概念差异、让 κ 更接近 1 → 属保守方向偏差，可以接受，但要在局限里写。

## 4 视觉核对（人工）

抽 `obj00 / seed 11` 的 5×3 网格（w ∈ {0.2,0.6,1.0,1.5,2.0} × s ∈ {4,7.5,12}）目视：

- 15 张全部是可辨的红茶壶，**没有黑图/纯噪声**。
- **w ≤ 1.0 几乎看不出差别；w=1.5 背景开始出铜绿（patina）；w=2.0 铜绿明显并出现边缘伪影。**
- 同一行内 s=4 / 7.5 / 12 的视觉差别远小于跨行（跨 w）的差别。

**这条与 Y4 的 `D_min` 独立吻合**：Y4 从数值上算出 w=2.0 时最好的 s 仍差 **9.12**，这里肉眼看到的就是"烧图"。
→ **w ≥ 1.5 的 κ 数值不可当等响应线用**，与 Y4 的浅谷判定一致。
